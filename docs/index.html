常見問題

放心開始，
有跡可循。

圖片會上傳嗎？一定要連網嗎？

圖片不會上傳做 AI 推論。第一次下載模型與選用的 GPU 套件需要網路，備齊後可離線推論。

我的電腦可以使用嗎？

需要 Windows x64 與 WebView2 Runtime，已測試 Windows 11。沒有 GPU 也能用 CPU；GPU 加速是選配。

安裝版選 *-setup.exe；免安裝版選 *-portable.zip，完整解壓縮並保留隨附的 analysis 資料夾。

語意搜尋可以輸入中文嗎？

目前請使用英文描述，例如 a photograph of a cat。搜尋前，先在「設定 → 本機 AI 與運算裝置」準備模型，並將圖片加入「背景分析佇列」，等待分析完成。

一般文字搜尋仍可比對中文檔名與相對路徑；只下載模型不代表圖片已完成分析。

整理會搬動原圖嗎？可以復原嗎？

搬移與改名會改動真實檔案；標籤、收藏和星等不改變位置。智慧整理先審核、預覽，確認套用後才執行。

智慧整理的復原紀錄可跨程式重啟，遇到檔案變更或位置衝突不任意覆寫。一般搬移／改名的 Ctrl+Z 僅限本次工作階段；刪除請從 Windows 回收筒還原。

復原不等於原圖備份。「圖庫維護與備份」匯出的管理資料不包含原始圖片，請另外備份原圖。

下載有安全警示，或遇到操作問題？

請確認檔案來自 Pixora 的 GitHub Releases，核對版本與警示內容，不要停用安全保護。

可到 回報問題 提供版本、重現步驟與錯誤訊息；附上截圖或紀錄前，請遮蔽私人圖片、路徑與個人資訊。
